# Creative OS V7 — Local + Multi-provider AI

Browser (Next.js 16)
  -> local PostgreSQL (`creative_os_db`)
  -> local filesystem storage (`./storage`)
  -> AI provider abstraction
       -> Gemini API (default)
       -> OpenAI API (optional fallback)
  -> production renderer (Sharp)
       -> AI-generated environment only
       -> real canonical pack/cookie assets composited afterward
       -> exact typography rendered locally

## Provider selection
`AI_PROVIDER=gemini` uses `GEMINI_API_KEY` and `GEMINI_MODEL`.
`AI_PROVIDER=openai` uses `OPENAI_API_KEY` and `OPENAI_MODEL`.
`IMAGE_PROVIDER` may be set independently; otherwise it follows `AI_PROVIDER`.

## Gemini specifics
- Text modules use Gemini Interactions API through `@google/genai`.
- Research may enable Google Search grounding with `GEMINI_ENABLE_SEARCH=true`.
- Image environments use Nano Banana 2 via `gemini-3.1-flash-image` by default.
- Product packaging and cookies are never generated by the model; canonical local assets are composited with Sharp.
